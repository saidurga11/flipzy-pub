# Flipzy Game Assets

## Tile Images

This directory contains placeholder tile images for the Flipzy card game.

### Current Assets (Placeholders)

For the initial implementation, we use colored squares representing different tile types:
- Colors are generated programmatically based on tile value
- No actual image files are required initially

### Future Assets

When adding actual artwork:
- `tile_back.png` - Back of card design (common for all tiles)
- `tile_N.png` - Front face for each unique tile type (N = 0-7 for 4x4 grid)

### Asset Requirements
- PNG format
- Square dimensions (recommended: 256x256px)
- Transparent background for front faces
- Optimized for mobile (< 50KB per image)
